    Queries run as a read-only role inside a transaction that is always rolled back; a script that tries to commit is stopped and a clean copy of the database is loaded. The database is the same one the project's pgTAP suite checks: a test compares every table and view here with the tested PostgreSQL, row by row. Data: StatsBomb Open Data. Challenges are inspired by the topics of Learn SQL Through Football (Apress); no material from the book is reused.
